# MemeLab

The internet's meme studio.

MemeLab is a fast, watermark-free workspace for discovering meme templates,
remixing them, and exporting finished images. This repository currently
contains the first product and visual checkpoint: a responsive template
library, search and category filters, local favorite interactions, editor
preview, and upload workspace.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```
